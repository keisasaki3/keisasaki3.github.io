# UIモックエディタ

ゲームアプリの画面UI配置をさっと作るための1ファイルのツール（2026-11-17 Keita依頼。機能はClaudeが選定）。`index.html` だけで動き、サーバー・ログイン・DBは使わない。なつめポータルの `/ui-mock/` に出る（`scripts/build-portal.sh`）。

- 部品: ボタン / 丸ボタン / テキスト / パネル / HPバー / アイコン枠 / メッセージ窓 / リスト / タブ / 十字キー / スティック / ミニマップ / 画像 / キャラ
- 操作: ドラッグで移動、四隅・辺のハンドルでサイズ変更、グリッド吸着と画面中央への吸着、2本指ピンチで拡大縮小、元に戻す/やり直し、複製・重なり順・ロック・非表示
- 画面: 複数の画面を持てる。サイズはプリセット（iPhone/Android/iPad/PC）か自由入力。背景色・背景画像。テンプレート（RPGバトル/アクション/タイトル/メニュー）
- 保存: 端末の `localStorage`（キー `uimock.v1`、表示設定は `uimock.v1.view`）に自動保存。PNG書き出し（2倍）、JSON保存・読み込み、画面のJSONをクリップボードへコピー（実装を頼むときに貼る用）
- 描画は部品ごとのSVGで、画面表示とPNG書き出しが同じ描画関数を使う
