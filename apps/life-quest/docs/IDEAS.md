## 3. 学問以外のステータス

> 2026-09-27 Keita決定・実装（`SPEC.md` §2・§4・§6・§7）: 上位単位は「ステータス」。資産・筋力もステータスとして扱い、分野・トピックの中に「握力 何kg」のような**入力型トピック**を作れる。入力型は★・Lvに含めない。オンライン/勉強中などは「状態」と呼び分ける。

- 資産、筋力なども人生クエスト上でステータスとして可視化したい。
- 現在の上位単位「学問」「科目」は、学習以外まで含めるには狭いため、名称とデータモデルを再検討する。
- 現行の基本構造は `学問 -> 分野 -> トピック`。過去仕様では `カリキュラムセット -> 科目 -> 単元` という整理も行っていた。
- 資産や筋力は、学習と同じ `MASTER数 = ★ = Lv` が自然とは限らない。無理に同一計算モデルへ押し込まず、共通UIと個別の測定方式を分けて考える。
- 「学問画面」「科目★」「プレイヤーLv」など既存名称も必要に応じて再検討する。

## 4. ユーザーカスタムを中核にする案

> 2026-09-27 Keita決定・実装（`SPEC.md` §2・§4・§8）: 自作ステータスを基本にし、プリセットは後から追加する形。初回はプリセット選択画面。29学問のまとまりの名称は「29学問」。筋力・語学などもそれぞれプリセットにする（中身は未作成）。

- ユーザー自身が、従来の「学問／科目」に相当する項目を自由に追加できるようにしたい。
- その配下へ分野やトピックを自由に追加・編集できるようにしたい。
- むしろこちらをアプリの基本形にし、現在の29学問は「29学問プリセットを追加」のように後から導入できる形式のほうが筋がよい可能性がある。
- 29学問を人生クエストそのものと同一視しない方向を優先的に検討する。

## 9. 新ゲーム性「スライム冒険」（2026-10-03 Keita原案、未決）

- 雇っているスライムを**ワンタッチで冒険に行かせる**だけの手軽な遊び。
- 行き先は**現実の世界遺産**。
- 冒険から帰ると**アイテム（その国の名産・名物など）**を拾ってきて、コレクションできる（昔のブラウザゲー風）。
- アイテムに**レア度**を設定して面白くする。
- 帰ってきたら、スライムが**その国がどんなだったか話してくれる**。
- 世界遺産・名産・国の知識も手に入るミニゲームにする。
- Keita: 「ゲーム性はもうちょっと工夫できそう」。
