# 人生クエスト — 現行仕様

更新日: 2026-09-26

## 1. 目的

人生クエストは、自分が何を理解しているか、次に何を学べるかを可視化し、現実世界で学ぶ動機を生む個人向け学習ステータスシステムである。

人生クエスト自体がすべての教材を抱え込むことは目的にしない。本、Wikipedia、論文、動画、人との会話、現地体験など、現実世界の外部リソースへ出て学び、その結果を人生クエストへ持ち帰る。

基本ループ:

1. 人生クエストで学ぶ対象を見つける
2. 外部へ出て学ぶ
3. 理解できたトピックをMASTERする
4. ★・Lv・NEXTが更新される
5. 次の学習対象を見つける

人生クエストは「安全基地」「ステータス画面」「指針」「メンター」の役割を担う。

## 2. 学習構造

基本階層は以下のみとする。

`学問 -> 分野 -> トピック`

- トピックは十分に小さい学習単位とする。
- 学習順序は強制しない。
- どのトピックも独立してMASTERできる。
- 1 MASTER = ★1。
- 難易度や学習時間で★の重みは変えない。
- MASTER解除時は★1を減算する。

### 科目★

科目★ = その科目でMASTER済みのトピック数。

### プレイヤーLv

プレイヤーLv = 全科目のMASTER済みトピック総数。

Lvと科目★は保存値にせず、MASTERデータから算出する。

## 3. NEXT

NEXTは推薦であり、必修順序ではない。

候補は原則として次の優先順位で決める。

1. 未MASTER
2. 前提トピックを満たす
3. 重要度が高い
4. 推奨順序が早い

利用者はNEXTを無視して別のトピックを先にMASTERしてよい。

数学 / 物理学 / 天文学 / 地球科学 / 化学 / 生物学 / 計算機科学 / 建築学 / デザイン学 / 農学 / 医学 / 歯学 / 薬学 / 政治学 / 軍事学・防衛学 / 法学 / 経済学 / 経営学 / 社会学 / 教育学 / 哲学 / 宗教学 / 心理学 / 言語学・語学 / 人類学・考古学 / 歴史学 / 地理学 / 文学 / 芸術

各学問は日本語名、英語名、アイコンを持つ。

## 5. カリキュラム方針

標準プリセットは大学一般教養から学部基礎程度までを目安とする。

ただし現在のカリキュラム整備では、まず日本の学習指導要領を基準に学校教育範囲を漏れなく地図化し、その後に大学教養・学問固有の重要領域を追加する。

数学は現在、小学算数・中学数学・高校数学をベースに細粒度トピック化している。

出典表記は以下を使用する。

- 小学算数
- 中学数学
- 小学算数・中学数学
- 高校 数学I / II / III / A / B / C 等

## 6. 学問一覧UI

基本表示例:

`🔢  数学  Math  ★9`

その下に:

`マスター済：9トピック  NEXT：○○`

要件:

- 学問名の左に小さな絵文字アイコン。
- 日本語名の隣に薄い英語名。
- ★数は学問名から離しすぎず、同一情報グループとして表示。
- パーセント進捗は表示しない。
- 不要な説明文を勝手に追加しない。

## 7. トピックUI

- 各トピックはチェックでMASTER / 未MASTERを切り替える。
- MASTERした瞬間、トピック右側に `MASTER!` を表示する。
- MASTER解除時に `MASTER!` も即時削除する。
- 各トピック右側に `★1` は表示しない。
- 出典は補助情報として小さく表示する。
- トピック検索を提供する。

現行Web版フォントは `Zen Kaku Gothic New`。

## 8. プレイヤー表示

上部表示は:

`{display_name} Lv.{master_count}`

名前は変更可能。

将来の共通アカウント導入後は、人生クエスト固有のハンドルではなく共通 `profiles.display_name` を使用する。

共通キャラクターは `profiles.race_id` で決まり、人生クエストと「午後三時、夏の果。」で同一種族・同一見た目を使う。

## 9. 共通ステータス

共通バックエンド導入後、以下の表示ステータスを共有する。

- studying: 勉強中
- reading: 読書中
- busy: 取り込み中
- afk: AFK

## 10. 設定

現行テスト用機能として「全チェックをリセット」を持つ。

- 全科目のMASTER状態を削除する。
- Lv / ★ / MASTER! はMASTERデータから再計算される。
- display_nameは保持する。
- 実行前に確認を出す。

## 11. 認証・同期

人生クエストと「午後三時、夏の果。」は同じSupabaseプロジェクトを利用する。

- 認証: Supabase Auth
- ログイン: Google OAuth + メール/パスワードを初期候補とする
- 共通識別子: `auth.users.id` (UUID)
- パスワードはアプリ独自DBへ保存しない
- プロフィール・種族・Presenceを共通化する
- 人生クエストのMASTER状態はSupabaseへ保存し、端末間同期を可能にする

当面は各アプリで一度ずつログインしてよい。将来、同一ドメイン配下または専用認証ドメインによるSSOを検討する。

## 12. データ正本

共通DB仕様は `/shared-world-core/` を正本とする。

人生クエスト固有データ:

- quest_subjects
- quest_fields
- quest_topics
- quest_topic_prerequisites
- quest_topic_mastery

科目★とプレイヤーLvは `quest_topic_mastery` から算出し、二重保存しない。

## 13. デイリー

デイリーは学習動機の入口として残す。

- デイリー教養
- デイリー基礎学問
- デイリーWORLD
- デイリーQUIZ

デイリーの読了やクイズ正解を自動的にMASTERへ変換しない。MASTERは本人の理解判断で行う。
