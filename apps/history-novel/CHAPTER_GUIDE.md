# 章づくりの基準（SUPER歴史ノベル）

> 呼び名: シナリオ（例「世界がつながる」）＞チャプター（場面ごと）。チャプターの始めの年号と見出しの窓は「チャプタータイトル」（2026-11-06）。

新しい章を作るときの手順と、出す前に満たす条件。基準は鎌倉編「武士の天下へ（平安～鎌倉）」と大航海時代編「世界がつながる（大航海時代）」。どちらも経太さんの指示を積み上げてできた形なので、ここにない判断をするときは README.md の「決まっていること」を優先する（2026-11-05 経太さん「クオリティを保つための基準メソッドを記録しといて」）。

## 1. 目的を外さない

- 学ぶのは**時代の大きな流れ**。合戦や事件の細部ではない。合戦は流れの一場面として扱い、寄るのは要所だけ。
- 章全体を一つの**問い**で貫く。冒頭で問い、最後に答える。
  - 鎌倉編: 兵も土地もない流人に、なぜ武士の世が開けたのか → 御恩と奉公。
  - 大航海時代編: 大艦隊を持つ明ではなく、なぜ西の端の小国が海をつないだのか → 外に出なければ豊かになれなかった小国の競争。
- 冒頭は**結末の一場面から入る**（伊豆に届いた書状、帰ってきたビクトリア号）。その後「話は○年前にさかのぼる」で時系列に戻す。
- 「いきなり出てくる出来事」を作らない。出来事の前に、なぜそうなったかの前段を一行入れる。
- 光と影の両方を書く（世界史なら征服・奴隷貿易・病気を省かない）。善悪の決めつけは避け、事実と当時の人の言葉で見せる。

## 2. 台本（S.js）

- 規模の目安: 80〜130行、場面（scene）15〜22、心の声の選択 2〜4、台詞（sp）20〜30。
- 地の文は1行60〜120字。句点で自動改行される。読み物ではなく「めくって進む」長さに。
- 場面ごとに `y`（西暦）`era`（時代）`e`（チャプタータイトルに出る見出し）を付ける。`w` は日本史の章だけ和暦を入れる。世界史の章には付けない（「日本は○○時代」は不要、2026-11-06 経太さん）。
- **台詞**は史料に残る発言を、読みやすく硬い口調（歴史SLG風）に言い換える。出典は画面に出さないが、作り話の名言を史実のように書かない。伝説・異説は地の文で「と伝わる」「とされる」を付ける。
- **心の声の選択**（`choice`）は予想クイズではなく、その人物の心の声。史実の選択肢に `h:1`、`a` に史実の番号。
  - 史実と違う選択は **IFルート** を3〜4行。最後は「実はこの道を本当に歩いた人がいる／半分は本当に起きた」と、**実在の人物・出来事につなげて学びにする**（木曾義仲、サン・アントニオ号、土木の変、悲しき夜など）。
  - `fb` で史実に戻し、なぜその選択だったかを一文で残す。
- 数字に幅がある所・異説がある所は `n:` の注で補う（船の大きさ、人口の見積もり、幕府の始まりの年など）。
- 章末の `ORDER`（流れ並べ替え）は6項目。年が離れていて順番が一つに決まるものだけを選ぶ（同じ年・入れ子になる出来事は入れない）。

## 3. 辞書（G.js）

- 本文に出る人名・地名・用語はすべて辞書に載せる（60〜90語）。読み仮名 `r`、年代 `y`、種類 `t`（"人"・"地"、用語は付けない＝本文で太字）。
- 説明は2〜4文。最初の一文で「何か」がわかるように。説明の中の語にも `{語}` を付け、辞書の中からさらに潜れるようにする。
- 人物の辞書名は `C` の表示名と同じにする（肖像が辞書に出る）。
- 1文字の語（明・銀など）は自動では押せるようにならないので、本文で `{明}` と明示する。

## 4. 地図（cfg.js・P・m）

- 地名 `P` は [経度, 緯度]。地図にピンが出る地名は、なるべく辞書（`t:"地"`）にも載せる（押すと辞書が開く）。
- 各行の `m` でカメラ（`c` 中心、`r` 半径＝短い辺の半分に入る距離。1度≒100）、点滅 `blink`、旗 `fl`、矢印 `ar` を指定。矢印の `s` は "s"（本筋・赤）"o"（その他・灰）"if"（IF・紫の点線）。
- 世界全体を見せる場面は `rw`（横幅の半分）を使う。PCは地図が横長、スマホは縦長なので、`r` だけだとPCで引きすぎる。
- スマホの地図は横幅が狭いので、東西に広い場面は `fw`（横幅の半分に最低限入れる距離）を付ける。PCでは効かず、スマホだけ引きになる。目安は東西の端の経度差の半分×94＋余白400（例: 鄭和の航海 `fw:4500`）。
- 太平洋をまたぐ航路は、アジア側を経度-360の写しで描く（マクタン島 -236 など）。地図とアジア側の地形には写しが入っている。
- 旗の色: 源氏=白 `w`、平氏・明=赤 `r`、ポルトガル=緑 `pt`、スペイン=黄 `es`、それ以外=紫 `k`。装飾目的の色は足さない。
- 地形は標高から作った陰影（明るい画面用と暗い画面用）。寄る場所だけ高精細の画像を足す（cfg.js の `terr`、`z` はこの半径より寄ったら出す）。作り方は `src/w1/gen_terrain.py`。

## 5. 人物と資料（pic.js・ch/・pic/）

- 肖像画はパブリックドメインの本物を使う。顔の切り抜きは 204×252。無い人物は一文字の影。
- 土地の資料は場面ごとに1〜2点（`img`）または地名ごと（`R`）。1章で15点前後。写真・当時の絵・地図を混ぜる。
- 画像はウィキメディア・コモンズから。作者とライセンスは API で取り、`pic.js` の `cr` に入れる（章末の「画像の出典」に自動で並ぶ）。CC BY / BY-SA はクレジット必須。現代の想像図・複製船は説明にそう書く。
- コモンズのAPIは連続で叩くと止められる（429）。ファイル名をまとめて1回で問い合わせ、画像は thumb.wikimedia.org の 960px を間を空けて取る。

## 6. 仕上げの確認（PR前に必ず）

1. `python3 src/build.py` でビルドし、`node --check` で構文を確かめる。
2. Playwright で**最後まで通し読み**する（Supabase への通信は止める＝本番DBに書かない）。選択は史実側とIF側の両方で1回ずつ。コンソールにエラーが無いこと。
3. スマホ（390×844）とPC（1280×800）で、場面ごとにスクリーンショットを撮って見る。見るところ:
   - カメラが話の場所を映しているか（地名・矢印が画面外に出ていないか。スマホは東西、PCは南北が切れやすい）
   - ラベルの重なり、台詞の窓が大事な所を隠していないか
   - 暗い画面（ダークモード）でも読めるか
4. 既存の章（鎌倉編）も通し読みして、共通部分の変更で壊れていないか確かめる。
5. タイトルの本棚（日本史・世界史）から章を行き来でき、部屋番号が引き継がれるか。
6. 事実の確認: 年号・人数・距離・引用を、少なくとも一つの信頼できる資料で確かめる。迷ったら「とされる」を付けるか削る。

## 7. 章を足す手順（ファイル）

1. `src/<章ID>/` を作り、`cfg.js`（page・shelf・room・地図の基準・章末の文言）、`S.js`、`G.js`、`pic.js`、地図パスを置く。
2. `src/build.py` の `CHAPTERS` に1行、`src/engine2.js` の `SHELF` の該当する時代に `page` を足す。
3. 画像を `ch/`・`pic/`、地形を `terrain-*.jpg` に置く。
4. 部屋の保存は章ごとに分かれる（`room` に章IDを入れると「章ID-部屋番号」で保存）。鎌倉編だけは部屋番号そのまま。
