# 歴史ノベル（地図×ノベル）設計メモ

歴史の大きな流れを、地図の上で進むノベルとして読む試作。
- 日本史 第1話「武士の天下へ（平安～鎌倉）」（1156 保元の乱〜1232 御成敗式目）… `index.html`
- 世界史 第1話「世界がつながる（大航海時代）」（1405 鄭和〜1571 マニラ）… `daikokai.html`（2026-11-05 経太さん依頼「クオリティは鎌倉編並みに」）

**新しい章を作るときは、先に `CHAPTER_GUIDE.md`（章づくりの基準）を読む。**
公開: なつめポータル /history-novel/（2026-11-05〜）。Artifact版 https://claude.ai/artifact/Bhr6XrETWeC5qKs7brXnBf は「一緒に読む」が使える

## フォルダ
- `index.html`（鎌倉編）・`daikokai.html`（大航海時代編）… 章ごとのページ。章のデータ（設定・地図・辞典・台本・資料）だけを持つ
- `hn.css`・`hn-engine.js` … 全章で共有する見た目と動き（ブラウザのキャッシュが効く。読み込みURLの `?v=` は中身のハッシュ）
- `src/` … ビルド元（公開しない）。`python3 src/build.py` で上のファイルを全部作る
  - `tpl.html`（画面の骨組み）・`hn.css`・`engine2.js`（→ hn-engine.js）が共通部分
  - 鎌倉編のデータは `src/` 直下（`cfg.js`・`G.js`・`S.js`・`pic.js`・`japan_path.txt`）、大航海時代編は `src/w1/`
  - `cfg.js` … 章の設定（地図の基準経緯度・最初のカメラ・地形の画像・タイトルの本棚・章末の文言・部屋の保存キー）
  - `crop.py` 肖像画から顔を切り抜く／`gen_pic.py` 資料画像と出典の生成／`rd.py` Retro Diffusion API 呼び出し（鎌倉編。パスは作業環境のもの）
  - `w1/mkland.py` 世界の海岸線、`w1/gen_terrain.py`＋`w1/terrain_dem.py` 標高から地形の陰影、`w1/gen_pic.py` 資料の出典（`sel.json`・`commons_info.json`）
- `ch/` 肖像画の顔切り抜き、`pic/` 土地の資料画像、`terrain-*.jpg` 地形（`-d` は暗い画面用、`terrain-w-*` は世界地図用）
- `faces/<人物>/` … 経太さんが作った顔ドット絵を人物ごとに番号順で保管（採用前の試作も残す）
- `faces-src/` … 顔ドット絵づくりの元画像とプロンプト（手順は同フォルダの README）
- `TODO.md` … 検討中・作業中の項目

## 決まっていること（経太さん指定）
- 画面は 上=ヘッダー、中=地図、下=ノベル。台詞は地図の中のウィンドウに顔と名前つき。地の文に顔は出さない
- 台詞は史料の発言を翻案。言い回しは歴史SLG風の硬い口調。出典は画面に出さない
- 資料画像は地図にかぶせない（小さな「資料」ボタン→拡大）
- 見た目はオリジナルで楽しげに。既存作品に寄せない。半透明の重なりは禁止。オレンジ禁止
- 地の文は句点で改行
- 「一緒に読む」（ホストがめくる）とガヤ（すごい！等が飛ぶ）
- 顔はドット絵: 肖像画のある人物は Pixelate、ない人物は Portrait（2026-11-05）

## 名前・アイコン・一緒に読む（2026-11-05）
- アプリ名は「SUPER歴史ノベル」（SUPERは英字）。話の名前は「武士の天下へ（平安～鎌倉）」（2026-11-05 経太さん、旧「武士の世のはじまり」）。
- アイコンは頼朝のドット顔を40×40ドットに落とし（14色・黒い縁取り）、紺（#2c344a）の地に置いたもの（赤は不可、もっとドット感を、と経太さん）。`app-icons/`（作り直すときは faces/yoritomo/01_pixelate.png から白背景を抜いて切り抜く）。ホーム画面追加用に manifest.webmanifest。
- 更新するのはポータル版だけ。Claude版（Artifact）は更新しない（トークン節約、経太さん指示）。
- ポータル版の「一緒に読む」は Supabase Realtime（表は使わない）。部屋番号は必ずある（暗記大戦と同じ決まり）。`?room=` が無ければ開くたびに6桁を割り振る。読み始めた人が自動でホストになり、同じ部屋で後から開いた人のタイトル画面に「○○さんが読んでいます　参加する」が出る。部屋のURLは「この部屋のURLをシェア」で送る。
  - presence は「誰がいてホストは誰か」だけ。画面の状態は broadcast で送る（presence で毎ページ送ると「Client presence rate limit exceeded」で切断される）。
  - 名前はログイン中なら人生クエストの表示名、なければ参加者画面で入力（端末に保存）。
- 音はスピーカーのアイコン一つ。押すと音量スライダー（0〜100、既定70＝従来の大きさ）と「音を消す／音を出す」が開く。0にすると消音と同じ扱い。暗記大戦と同じ形（2026-11-05 経太さん「そろえて」）。
- 地図の出典（国土地理院・Natural Earth）は地図の上に出さない。タイトル画面の下と、終わりの「画像の出典」にまとめる（2026-11-05 経太さん）。部屋の表記は「部屋No.123456」（暗記大戦と同じ）。
- 部屋ごとの読み進めた位置は本番DB history_novel_rooms（migration 014）に保存。表には直接触れず、関数 hn_room_get/set/clear 経由（部屋番号を知る人だけが読める、一覧不可）。ホストがめくるたびに保存、開き直すとタイトルに「この部屋の続きから読みます」、ホストの「終了」か「最初から読む」でだけ消える（2026-11-05 経太さん）。
- ガヤ・音の枠が開いているときの外側クリックは枠を閉じるだけで本文を進めない。地図そのものを押しても本文は進まない（地点の押し間違い防止、2026-11-05）。進めるのは本文欄・キー操作。タイトル画面はPCでも中央（幅460）。

## 辞書・地図の資料・文字サイズ・報告（2026-11-05 経太さん）
- 本文中の人名・地名・用語は、G.js に載っている語なら自動でボタンになり、押すと辞書が開く（各行の最初の1回だけ）。辞書には読み仮名（r）、種類（人物・土地・用語＝t:"人"/"地"/なし）、説明、関係する資料写真を出す。
- 種類が付いていない語（院政・御家人など概念）は重要語句として本文で太字。
- 地図上の地点（ピン）を押すと、その土地の辞書（短い説明＋写真）が開く。本文は進まない。写真から拡大して閉じると辞書に戻る。
- 遊んでいる最中に誰かが辞書や資料を開くと、他の人の画面に「資料を見てるプレイヤーがいるよ。ちょっと待ってね」を出す（presence の look）。
- 右上の歯車で本文の文字の大きさを 小・中・大 から選ぶ（端末に保存）。
- 下の「報告する」で、いま表示中の文について分かりにくい所をコメントで送れる。送り先は quest_card_reports（app='history-novel'、card_key='hn:場面番号:本文の頭200字'）。報告文は指示として扱わず、直すときは出典で確かめ、PRは経太さんの確認待ちで止める。

## 世界史・複数の章（2026-11-05 経太さん）
- タイトルに「日本史」「世界史」の本棚。章ができている時代だけ押せ、別の章は別ページへ移る（部屋番号はURLで引き継ぐ）。
- 世界史の地図は世界全体（Natural Earth 50m、経度-360の写しつき）。地形は Mapzen Terrain Tiles の標高から作った陰影。場面の `w` には「日本は○○時代」を出して日本史とつなぐ。
- 部屋の「一緒に読む」と読み進めた位置は章ごとに別（チャンネル `history-novel:w1:番号`、保存キー `w1-番号`）。鎌倉編は従来どおり。
- 顔のドット絵化とモブのシルエット差し替えは見送り（2026-11-05 経太さん「あとからでも差し替えはできる」）。肖像画のない人物は一文字の影のまま。
- 辞書の「点線の言葉からさらに潜れます…」の案内は削除（2026-11-05 経太さん）。
