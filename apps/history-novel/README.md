# 歴史ノベル（地図×ノベル）設計メモ

歴史の大きな流れを、地図の上で進むノベルとして読む試作。第一章「武士の世のはじまり」（1156 保元の乱〜1232 御成敗式目）。
公開: なつめポータル /history-novel/（2026-11-05〜）。Artifact版 https://claude.ai/artifact/Bhr6XrETWeC5qKs7brXnBf は「一緒に読む」が使える

## フォルダ
- `index.html` … ビルド済みの本体（1ファイル）。なつめポータルの /history-novel/ で公開（src・faces・faces-src は公開しない）
- `src/` … ビルド元。`build.py` が `tpl.html` に `G.js`（辞典）・`S.js`（台本）・`pic.js`（資料画像）・`engine2.js`・地図パスを差し込む
  - `crop.py` 肖像画から顔を切り抜く／`gen_pic.py` 資料画像と出典の生成／`rd.py` Retro Diffusion API 呼び出し
  - `python3 src/build.py` で ../index.html を作る。crop.py・gen_pic.py・rd.py 内のパスは作業環境のもの
- `ch/` 肖像画の顔切り抜き、`pic/` 土地の資料画像、`terrain-*.jpg` 地形（`-d` は暗い画面用）
- `faces/<人物>/` … 経太さんが作った顔ドット絵を人物ごとに番号順で保管（採用前の試作も残す）
- `faces-src/` … 顔ドット絵づくりの元画像とプロンプト（手順は同フォルダの README）
- `TODO.md` … 検討中・作業中の項目

## 決まっていること（経太さん指定）
- 画面は 上=ヘッダー、中=地図、下=ノベル。台詞は地図の中のウィンドウに顔と名前つき。地の文に顔は出さない
- 台詞は史料の発言を翻案。言い回しは歴史SLG風の硬い口調。出典は画面に出さない
- 資料画像は地図にかぶせない（小さな「資料」ボタン→拡大）
- 見た目はオリジナルで楽しげに。既存作品に寄せない。半透明の重なりは禁止。オレンジ禁止
- 地の文は句点で改行
- 「一緒に読む」（ホストがめくる）とガヤ（すごい！等が飛ぶ）
- 顔はドット絵: 肖像画のある人物は Pixelate、ない人物は Portrait（2026-11-05）

## 名前・アイコン・一緒に読む（2026-11-05）
- アプリ名は「SUPER歴史ノベル」（SUPERは英字）。章名「武士の世のはじまり」は章のタイトルとして残す。
- アイコンは頼朝のドット顔を切り抜き、赤（--accent #a3282a）の地に置いたもの。`app-icons/`（作り直すときは faces/yoritomo/01_pixelate.png から白背景を抜いて切り抜く）。ホーム画面追加用に manifest.webmanifest。
- 更新するのはポータル版だけ。Claude版（Artifact）は更新しない（トークン節約、経太さん指示）。
- ポータル版の「一緒に読む」は Supabase Realtime（表は使わない）。「一緒に読む」を押すと `?yomu=あいことば` 付きのリンクができ、それを開いた人がホストの画面に合わせて進む。
  - presence は「誰がいてホストは誰か」だけ。画面の状態は broadcast で送る（presence で毎ページ送ると「Client presence rate limit exceeded」で切断される）。
  - 名前はログイン中なら人生クエストの表示名、なければ参加者画面で入力（端末に保存）。
