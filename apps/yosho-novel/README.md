# SUPER洋書ノベル（設計メモ）

洋書（パブリックドメインの英語の小説）を、地図の上で進むノベルとして原文のまま読む英語学習アプリ。SUPER歴史ノベルと同格の別アプリ（2026-11-15 経太さん「名称はSUPER洋書ノベル。歴史ノベルと同じレベルで個別アプリとして」）。
設計案: https://claude.ai/artifact/HTFz9FzYj7UkzBUV57SpHm

## 決まっていること（2026-11-15 経太さん）
- 第1話はドイル「ボヘミアの醜聞」（A Scandal in Bohemia, 1891）。
- 英文は**原文全文**。書き換えも削除もしない。1行は1〜2文。
- 和訳は自作（既存の日本語訳は使わない）。既定は「押したときだけ」（「訳」ボタン）。歯車で「いつも／出さない」に変えられる（localStorage `yn-ja`）。
- 読み上げはブラウザの音声合成（英国英語の声を優先）。後で良い音声に差し替えられるよう、行に `au`（音声ファイル）があればそちらを流す。歯車で「押したとき／自動」（`yn-say`）。
- 地図は1880年代ごろのロンドン古地図（Bacon's New Ordnance Map of London、パブリックドメイン、Wikimedia Commons／BnF Gallica）。仕上げのPRで入れる。
- 文字の初期値はドット（歴史ノベルと同じ）。
- 章末の瞬間英作文はトライアル（`CFG.flash`、採点しない・飛ばせる）。

## しくみ
- エンジンは SUPER歴史ノベルと共有（`apps/history-novel/src/engine2.js` → `hn-engine.js`、`hn.css`、`tpl.html`）。`CFG.lang:"en"` の章だけ英語の機能が働く。共通の音・フォントは `../history-novel/` から読む（`HN_LIB`）。
- ビルドは `python3 apps/history-novel/src/build.py`（`CHAPTERS` に洋書ノベルの行がある）。出力は `apps/yosho-novel/index.html`。
- 章データは `src/holmes1/`（`cfg.js`・`S.js` 台本・`G.js` 辞書・`pic.js`・`london_path.txt`）。
- 台本: `t` 原文、`ja` 和訳、`sp` 話し手、`n` 注、`choice`＋`dd:1` は推理（手がかりを選ぶ。IFは出さない、章末の用語帳に「推理」の成績）、`recall`＋`rw`（表示する活用形）は伏せ字。
- 辞書: 見出しは英語。`ipa` 発音、`pos` 品詞、`ja` 意味、`modern` いまの英語では（今も使う言い方・例文。特定の読者の仕事や立場に寄せない）、`d` 説明、`forms` 活用形、`t`（"人"・"地"・"俗"=当時の暮らし）。
- 地図: `CFG.k`（1度あたりの描画単位）を 5000 にして街の縮尺で描く。
