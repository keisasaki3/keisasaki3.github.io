# 激突！暗記大戦（anki-taisen）設計書

なつめポータルのアプリのひとつ。友人や家族とオンラインで当て合う対戦型の暗記ゲームで、あらゆる分野の学びをここに集めていく（2026-11-02 Keita依頼、2026-11-03「ここにあらゆる学びを集積」）。

- 公開URL: https://natsume-portal.onrender.com/anki-taisen/ （旧 https://keisasaki3.github.io/apps/anki-taisen/ は開くと転送） （`?room=番号` で個室。省略時は誰でも入れるオープンルーム。§6）
- 更新するのはこの公開版だけ。claude.ai の Artifact 版（https://claude.ai/artifact/PWihQRKdReNW4YjamVfDeZ）は更新しない（2026-11-03 Keita決定、トークン節約）。

## 1. 構成

- `index.html`: ビルド済みの単一HTML（`src/pubhead.html` ＋ ビルド結果）。直接編集しない。
- `src/src.html`: 本体のソース（正本）。`src/build.py` が鳥・木・歴史の素材情報と学問の札を埋め込み、`index.html` と `data/` を作る。
- `data/<科目>.json`: 学問の札（選んだ科目だけ遅延読み込み）。`data/dx-history.json`・`dx-en.json` は用語辞典、`data/topics.json` は人生クエストのトピック → 札の枚数。
- `b/`（鳥の写真・鳴き声、`*-2.*` は2枚目／2つ目）、`t/`（木）、`h/`（歴史の資料画像）、`ci/`（学問の資料画像）、`map.js`（地図）。
- アイコンはリポジトリ直下の `/shared/icons/`（人生クエストと共用、`shared/README.md`）。
- ビルドの入力のうち、学問の札の原稿（`concepts/*.json`、英語辞書 `dict-en.json`、資料画像 `concepts/img/`）と鳥の原稿（`birds.js`）は作業フォルダ（Claudeのプロジェクトファイル `mekuri-battle/`）にある。`src/` はビルドスクリプトと素材メタデータの控え。鳥・木の元画像や録音そのものは控えていないので、既存の `b/` `t/` を作り直すときは取り直しになる。

## 2. ジャンル（2026-11-03 Keita決定）

- 1段目は「学問」「教養」の2つだけ（「雑学」という名前は使わない）。中間のまとまりは必要なときだけ（例: 化学 › 化学用語、英語 › ビジネス英単語／熟語・句動詞、鳥 › 関東の鳥／北海道の鳥、木 › 関東の木）。
- 2026-11-05（Keita指摘「上位と下位が同じ見た目でバッドUI」）: 1段目（学問／教養）はタブ、2段目以降はタブにつながる薄い色の囲みの中に並べる。3段目には上の段の名前を小さく添える。選んだ札は塗りつぶし。
- 段ごとに並べ、選んだものの中身だけを下の段に出す。まとまりを押すと中の最初のジャンルが選ばれ、下の設定も追従する。パンくずや「選んでいるのは」表示は出さない。
- 2026-11-04 学問に心理学・社会学・物理学・生物学・地学・天文学、統計学・マーケティング・医学・宗教学・美術史・文学を追加（各68〜103枚、全札に人生クエストのトピック）。
- 2026-11-04 学問に日本語（id 7）・英語 › 英語定型表現（id 8, en:1）、教養に世界遺産9・建築a・名画b・クラシックf・料理c・旬の食材e・酒d・星座g を追加（各57〜83枚）。教養の札は SUBJ に `k:1` を付け、`tp` は空（人生クエストに該当トピックが無いため）。SUBJ の id は1文字（数字・小文字も可）。
- 新しいジャンルは人生クエストのトピックを目次にして作り、全札に `tp`（人生クエストの `topic_id`）を付ける。

## 2.1 難易度のレベル感（2026-11-04 Keita決定：札を作る前に必ずこれに照らす）

- 共通: 下のレベルだけで、その分野の「おおまかな流れ・基本」がひととおり押さえられること。上のレベルは下を前提に積み上げる。札の枚数あわせのために足さない（重要だと資料にある事項だけ）。いきなり出てくる札を作らない（「滅亡」「分裂」などには前段の札を置く）。
- 歴史
  - やさしい: 中学社会（歴史）の基本事項。各時代・各地域の始まりと終わり、その中心の出来事。これだけで流れが一本につながる。
  - ふつう: 中学教科書の太字＋高校の基本事項。やさしいの出来事の原因・結果をつなぐ札。
  - むずかしい: 高校 日本史探究・世界史探究の重要事項。
- 学問（基礎／応用）
  - 基礎: 高校教科書・入門書で最初に出てくる用語。ニュースや会話を理解するのに必要なもの。
  - 応用: 大学教養〜実務で使う用語。基礎の用語を前提にする。
- 教養（基礎／応用）
  - 基礎: 一般常識として名前を聞いたことがあり、見れば分かるべきもの。
  - 応用: 愛好家の入門レベル。旅行・鑑賞・会話で一歩踏み込めるもの。
- 鳥・木: やさしい＝街や公園でまず見るもの、ふつう＝少しマイナーなもの、今月＝季節に合うもの（従来どおり）。

## 3. 対戦

- 同期は Supabase `shared-world-core` の Realtime presence（チャンネル `anki-taisen:<room>`）。
- ルール（Keita指定）: 制限時間なし（2026-11-02 タイマー廃止、2026-11-10 Keita「タイマーはなしを正に」）。各自が答えたらすぐ答え合わせ、次の札へは全員のOK待ち（止まったら「そろった人ではじめる」等）。正解は全員1点で早押しの優劣なし。最後の3問は得点2倍（途中から始めた分を除いて6問以上のとき）、歴史は±3年で0.5点。
- 版の照合（2026-11-11 Keita採用）: ページのスクリプトの中身から版（APP_VER）を作って presence に載せ、部屋に版のちがう人がいるとロビーに「全員でページを再読み込みしてください」を出す（古いキャッシュで札がずれるのを防ぐ）。
- 歴史の年の答え方（2026-11-04 Keita決定「細かい事象の年号まで覚える必要は微妙」）: 年まで答えるのは「やさしい」（lv1）の札だけ。ほかの札は同じ世紀か±10年なら満点（「正解（いつごろ）」と表示、yearRough）。入力欄の下に「年まで答える基本の札」「いつごろでOK」を出す。答え合わせでは正確な年を見せる。
- 部屋にほかの人がいても「ひとりで遊ぶ」で一人で始められる（2026-11-04 Keita依頼。ひとり用の対戦はほかの人の「参加する」に出ない。今日の復習も同じ）。
- ロゴは配色で変えない決定版（こげ茶の地に生成りの字、「突」「暗記」は若草。2026-11-04 Keita決定）。パスボタンは背景と区別できる枠と影つき。
- 音量（2026-11-05 Keita依頼）: 対戦中はスピーカーのアイコン1つ（消音・音量0は斜線）。押すと音量スライダーと「音を消す」の枠が開き、外を押すと閉じる（歴史ノベルとそろえた）。ロビーの「音」欄でも同じ調節ができる。0〜100、端末ごと nb-vol。効果音・鳴き声・曲すべてに効く。
- 文言（2026-11-05 Keita指定）: 対戦中の「やめる」→「ゲームをやめる」、ロビーの「配色」→「テーマカラー」。
- 配色は「明るい／暗い」と、緑の「若草／常磐」（端末ごと、`localStorage`）。ロビーにゲーム説明は置かない。

- 2026-11-05 答え方「入力／4択」を選べるようにした（Keita依頼、端末ごと nb-amode、歴史は従来どおりテンキー）。

- 問題形式（札に誤答 w がある数学・簿記）の正誤は、選んだ選択肢の文字列そのもので判定する（入力の照合 normAns はかっこ書きを消すので、式「(2, −3)」などが空になり正誤が逆になっていた。2026-11-11）。
- 2026-11-08 数学（学問、id "h"、concepts/math.json、71問。Keita依頼「概念名だけでなくちゃんと数学が上達するように。四則演算など小学生範囲は不要」）: 用語当てでなく問題形式。d=問題文、t=正解、w=誤答3つ（符号ミス・公式の取り違えなど典型的な間違いから作る）、x=解き方とコツ、k=札ID（答えが重なるので学習記録のキーは sj.id+":"+k）。w がある札は choicesFor が w から4択を作り、答え方は常に4択（入力欄・答え方の選択を出さない）。辞書リンクには入れない（build.py で math を DIDX から除外）。レベル: 基礎=中3〜高校の基本（式と方程式・関数・図形と三角比・指数対数・数列・微分積分・確率場合の数）、応用=数III・大学教養・実務（極限と級数・微積分の発展・線形代数・確率統計の発展・実務の数学）。正解はすべて sympy で検算（スクラッチの check.py）。

## 4. 学習記録と人生クエスト連携（2026-11-03 Keita依頼）

- 札ごとに「正解した日数」（1日1回まで）と「定着度」0〜3（別の日に正解で+1、不正解で-1、最後に見てから30日ごとに1下がる）を記録する。
- 「今日の復習」: 定着度に応じた間隔（0/1/3/7日）が来た札を、ジャンルをまたいで最大20枚出す。必要な科目（IDは大文字・小文字・数字）を先に読み込む。
- 4択での正解は、2日分（別の日に2回）で定着度が1段上がる（入力での正解は1日で1段。当て勘が混ざるため、2026-11-11 Keita採用）。途中の印 `h` は端末の記録だけに持ち、人生クエストには段だけ保存する。数学・簿記など4択しかない科目も同じ。
- ログインしなくても遊べる（記録は端末の `localStorage` `nb-learn`）。ロビーの一番下の「人生クエストと連携」から人生クエストにログインすると、記録を `quest_card_progress`（migration 013）にも保存し、端末の記録と新しいほうでまとめる。なつめポータル（`natsume-portal.onrender.com`、ROADMAP「置き場所」）では人生クエストと同じアドレスの下に並ぶので、ログインは共通。連携欄のログインは「人生クエストでログイン」1つだけで、押すとそのままGoogleでログインし暗記大戦に戻る（2026-11-03 Keita指定）。
- 人生クエストでは、トピックの右に「習得 ○%」（定着度の合計 ÷ (3 × 札の枚数)）を出す（人生クエストの SPEC §20）。

- 人生クエストでログインすると、人生クエストの表示名（profiles.display_name、「名無し」以外）を暗記大戦の名前に反映する（2026-11-04 Keita依頼）。あとで手で変えてもよいが、次にログイン状態を読み込んだときに表示名に戻る。

- 2026-11-04 画像で出題（Keita決定）: 見た目で覚える札は画像を見て用語を入力する。印は concepts/visual.json（科目→用語の一覧。build.py が札に `v:1`、src/visual.json に控え）。対象は世界遺産・名画・旬の食材の全札、建築（建物・様式）、クラシック（作曲家・楽器・楽語）、星座（星座・星の並び）、料理（日本・世界の料理）、美術史（様式・美術館）、地理の地形、地学の火山・岩石、生物の体・免疫、天文の太陽月・太陽系・銀河。画像に答えの文字が写るもの（星座図のラテン名で自明なもの、看板・ポスター・ラベル入り）や図表は外した。ロビーの「出題のしかた」は まぜる（印のある札だけ画像）／画像で（画像のある印つき札だけ）／説明で。S.mode を歴史の出題範囲（J/W/M）と共用するが、保存先は分ける（歴史 nb-mode、学問・教養 nb-cmode、初期値は「まぜる」）。ジャンルを切り替えるたび modeFor() で読み直す（2026-11-05 修正: 共用だったため日本史=J が学問で「画像で」と解釈され「この画像は何？」だけになっていた）。2026-11-05 見直し: 画像から答えようのない抽象語（恒常性・ホルモン・獲得免疫・核融合・万有引力の法則・マグマ・火成岩・放射年代測定・アレグロ等）を印から外し、生物に染色体・ミトコンドリア・葉緑体・気孔・系統樹を追加。画像出題の札が無い科目では欄を出さず説明で出題。
