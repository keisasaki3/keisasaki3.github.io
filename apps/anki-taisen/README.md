# 激突！暗記大戦（anki-taisen）設計書

なつめポータルのアプリのひとつ。友人や家族とオンラインで当て合う対戦型の暗記ゲームで、あらゆる分野の学びをここに集めていく（2026-11-02 Keita依頼、2026-11-03「ここにあらゆる学びを集積」）。

- 公開URL: https://natsume-portal.onrender.com/anki-taisen/ （旧 https://keisasaki3.github.io/apps/anki-taisen/ は開くと転送） （`?room=あいことば` で部屋を分けられる。省略時は `main`）
- 更新するのはこの公開版だけ。claude.ai の Artifact 版（https://claude.ai/artifact/PWihQRKdReNW4YjamVfDeZ）は更新しない（2026-11-03 Keita決定、トークン節約）。

## 1. 構成

- `index.html`: ビルド済みの単一HTML（`src/pubhead.html` ＋ ビルド結果）。直接編集しない。
- `src/src.html`: 本体のソース（正本）。`src/build.py` が鳥・木・歴史の素材情報と学問の札を埋め込み、`index.html` と `data/` を作る。
- `data/<科目>.json`: 学問の札（選んだ科目だけ遅延読み込み）。`data/dx-history.json`・`dx-en.json` は用語辞典、`data/topics.json` は人生クエストのトピック → 札の枚数。
- `b/`（鳥の写真・鳴き声、`*-2.*` は2枚目／2つ目）、`t/`（木）、`h/`（歴史の資料画像）、`ci/`（学問の資料画像）、`map.js`（地図）。
- アイコンはリポジトリ直下の `/shared/icons/`（人生クエストと共用、`shared/README.md`）。
- ビルドの入力のうち、学問の札の原稿（`concepts/*.json`、英語辞書 `dict-en.json`、資料画像 `concepts/img/`）と鳥の原稿（`birds.js`）は作業フォルダ（Claudeのプロジェクトファイル `mekuri-battle/`）にある。`src/` はビルドスクリプトと素材メタデータの控え。鳥・木の元画像や録音そのものは控えていないので、既存の `b/` `t/` を作り直すときは取り直しになる。

## 2. ジャンル（2026-11-03 Keita決定）

- 1段目は「学問」「教養」の2つだけ（「雑学」という名前は使わない）。中間のまとまりは必要なときだけ（例: 化学 › 化学用語、英語 › ビジネス英単語／熟語・句動詞、鳥 › 関東の鳥／北海道の鳥、木 › 関東の木）。
- 段ごとに並べ、選んだものの中身だけを下の段に出す。まとまりを押すと中の最初のジャンルが選ばれ、下の設定も追従する。パンくずや「選んでいるのは」表示は出さない。
- 2026-11-04 学問に心理学・社会学・物理学・生物学・地学・天文学、統計学・マーケティング・医学・宗教学・美術史・文学を追加（各68〜103枚、全札に人生クエストのトピック）。
- 2026-11-04 学問に日本語（id 7）・英語 › 英語定型表現（id 8, en:1）、教養に世界遺産9・建築a・名画b・クラシックf・料理c・旬の食材e・酒d・星座g を追加（各57〜83枚）。教養の札は SUBJ に `k:1` を付け、`tp` は空（人生クエストに該当トピックが無いため）。SUBJ の id は1文字（数字・小文字も可）。
- 新しいジャンルは人生クエストのトピックを目次にして作り、全札に `tp`（人生クエストの `topic_id`）を付ける。

## 3. 対戦

- 同期は Supabase `shared-world-core` の Realtime presence（チャンネル `anki-taisen:<room>`）。
- ルール（Keita指定）: 1問10秒、全員が答えたら答え合わせ、正解は全員1点で早押しの優劣なし。最後の3問は得点2倍、歴史は±3年で0.5点。
- 部屋にほかの人がいても「ひとりで遊ぶ」で一人で始められる（2026-11-04 Keita依頼。ひとり用の対戦はほかの人の「参加する」に出ない。今日の復習も同じ）。
- ロゴは配色で変えない決定版（こげ茶の地に生成りの字、「突」「暗記」は若草。2026-11-04 Keita決定）。パスボタンは背景と区別できる枠と影つき。
- 配色は「明るい／暗い」と、緑の「若草／常磐」（端末ごと、`localStorage`）。ロビーにゲーム説明は置かない。

## 3.1 答え方（2026-11-04 Keita決定）

- 学問・鳥・木は入力で答える（4択はやめた）。全角半角・大文字小文字・ひらがなカタカナ・空白や中黒・かっこ書きの違いは無視して照合する。
- 札ごとの別解（読みがな・別名・略称）を `concepts/alias/<科目>.json` に持ち、build.py が札の `a` に入れる。学問は英語名でも正解（英語の穴埋めは除く）。
- それでも割れたら、答え合わせの「間違いを報告する」で「正解なのに誤答になった」にチェックして送ると本人が正解にできる（§5）（点・学習記録も正解扱い、ほかの人には「正解（自己判定）」と見える）。
- 別解の足りないものは報告ボタンで集めて足す。

## 4. 学習記録と人生クエスト連携（2026-11-03 Keita依頼）

- 札ごとに「正解した日数」（1日1回まで）と「定着度」0〜3（別の日に正解で+1、不正解で-1、最後に見てから30日ごとに1下がる）を記録する。
- 「今日の復習」: 定着度に応じた間隔（0/1/3/7日）が来た札を、ジャンルをまたいで最大20枚出す。
- ログインしなくても遊べる（記録は端末の `localStorage` `nb-learn`）。ロビーの一番下の「人生クエストと連携」から人生クエストにログインすると、記録を `quest_card_progress`（migration 013）にも保存し、端末の記録と新しいほうでまとめる。なつめポータル（`natsume-portal.onrender.com`、ROADMAP「置き場所」）では人生クエストと同じアドレスの下に並ぶので、ログインは共通。連携欄のログインは「人生クエストでログイン」1つだけで、押すとそのままGoogleでログインし暗記大戦に戻る（2026-11-03 Keita指定）。
- 人生クエストでは、トピックの右に「習得 ○%」（定着度の合計 ÷ (3 × 札の枚数)）を出す（人生クエストの SPEC §20）。

- 人生クエストでログインすると、人生クエストの表示名（profiles.display_name、「名無し」以外）を暗記大戦の名前に反映する（2026-11-04 Keita依頼）。あとで手で変えてもよいが、次にログイン状態を読み込んだときに表示名に戻る。

- 2026-11-04 画像で出題（Keita決定）: 見た目で覚える札は画像を見て用語を入力する。印は concepts/visual.json（科目→用語の一覧。build.py が札に `v:1`、src/visual.json に控え）。対象は世界遺産・名画・旬の食材の全札、建築（建物・様式）、クラシック（作曲家・楽器・楽語）、星座（星座・星の並び）、料理（日本・世界の料理）、美術史（様式・美術館）、地理の地形、地学の火山・岩石、生物の体・免疫、天文の太陽月・太陽系・銀河。画像に答えの文字が写るもの（星座図のラテン名で自明なもの、看板・ポスター・ラベル入り）や図表は外した。ロビーの「出題のしかた」は まぜる（印のある札だけ画像）／画像で（画像のある印つき札だけ）／説明で。歴史の出題範囲と同じ mode 欄（M/J/W）を使う。画像出題の札が無い科目では欄を出さず説明で出題。
- 人生クエストを開くリンクは、PC（hover可・細いポインタ）では新しいタブで開く。
- 用語辞書は、スマホでは下から出るシート、PC（幅700px以上・hover可）では画面中央のカードで出す（2026-11-04 Keita指摘）。

## 5. 資料の誤り報告（2026-11-03 Keita依頼）

答え合わせの「間違いを報告する」1つに統一（2026-11-04 Keita指定）。開くとチェック欄「正解なのに誤答になった」（入力が不正解のときだけ表示、送るとその場で正解扱い）・「資料が間違っている」・「その他」と任意の一言欄。送ると `quest_card_reports` に「用語｜[種類]入力:…｜一言」で入る（書き込みのみ、読むのは管理側）。誤答判定の報告は別解ファイルに足す材料にする。Claudeが定期的に読んで札を直す。


- 2026-11-04 資料画像を全ジャンルに拡大（Keita「全部ちゃんと資料つけて」）: 札の用語→Wikidata（jawikiの記事名、だめなら英語名でenwiki）→P18画像→Commonsのライセンス確認（PD・CC0・CC BY/BY-SA・FAL等のみ、GFDLのみ・非自由は除外）→幅600pxで取得（透過図は白地）→一覧シートで目視し取り違え・判読不能を除外。913枚追加（計968枚）。ファイル名は <科目>-wNNNN.jpg、索引は concepts/img/index.json。作業スクリプトはセッションのscratchpad/img（resolve/fetch/dl/merge）。

## 6. 素材と権利

- 写真は Wikimedia Commons、鳴き声は xeno-canto。撮影者・録音者・ライセンスを表示する。鳴き声は CC BY-NC 系なので非営利で使う（収益化するなら先に差し替える）。GFDLのみの画像は使わない。AI生成の写真・音声は使わない。
- publishable key は公開してよい値。service role key は置かない。
