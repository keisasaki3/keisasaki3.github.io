## 遊びの流れ

1. タイトルでランクを選ぶ（見習い／一人前／店長。たたき台なので全部最初から選べる。最高評価を★で表示）
2. **先輩の手本**: 先輩 Sam が客を1人さばく会話を1行ずつ聞く（飛ばせる）
3. **本番**: 客5人。1人目は常連の Mr. Grant、ほかに常連 Lily・Mrs. Patel と通りすがり2人
4. **ハプニング**: シフトに1回、売り切れ／注文変更／苦情のどれか
5. **結果と持ち帰り**: 星1〜3、給料$10＋チップ。うまく言えなかった言い回しは「手帳」へ

## 1人の客の流れ

1. 客が英語で注文する（音声合成。字幕・訳はボタンで出す）
2. 注文パッド（drink / size / hot・iced / food / for here・to go）で作る。客が言わなかった項目は「聞く」で質問する
   - 質問は「話す場面」になる（下記）。もう言われた項目を聞くと客は少し不満になる
   - 違うものを出すと客に指摘され、作り直し
3. お会計を言う（メニュー表で計算する）
4. 満足度（0〜3）に応じてチップ（満足度×$0.50）

## 話す場面（ランクで答え方が変わる）

| ランク | 答え方 | 客の話す速さ |
| --- | --- | --- |
| 見習い | 英文3つから選ぶ（ひっかけは失礼な言い方・無関係な文・違う金額） | ゆっくり（0.85） |
| 一人前 | 単語タイルを並べて文を作る（ひっかけ単語2つ入り）。完全一致で正解 | ふつう（0.95） |
| 店長 | 声（ブラウザの音声認識）か打ち込み。言い方パターンに合えば自動で正解、外れたらお手本と比べて自己判定（SUPER暗記大戦の和文英訳と同じ方式） | 速め（1.05） |

判定にAIは使わない。言い終わるとお手本を読み上げる。

言い回し（`PHRASES` と `phraseFor`）: サイズを聞く／ホットかアイスか／店内か持ち帰りか／お会計（金額は計算）／売り切れを謝る／変更を引き受ける／苦情に謝って作り直す／世間話を返す（Lily）。

## 常連

- **Mr. Grant**: 毎回1人目。初回は「いつもの」の中身（medium・hot・coffee・for here）を言う。2回目以降は "The usual, please." だけ。覚えていれば質問なしで出せる。手帳に常連メモ
- **Lily**: 最初に "How's your day going?" と世間話。早口
- **Mrs. Patel**: ていねいな言い方。ゆっくり

## 手帳（復習）

- うまく言えなかった言い回しが入る。次のシフトでは手帳にある質問の項目を客が言わない／手帳にあるハプニングが起きる
- 2回言えたら手帳から消える
- 勉強用の別画面は作らない（「失敗した場面の客がまた来る」形で復習する）

## 音声

- 読み上げはブラウザの音声合成（`speak()` 1か所に集約。後で良い音声に差し替えられる）
- 音声認識は Chrome / Safari の `webkitSpeechRecognition`。無い端末は打ち込み
