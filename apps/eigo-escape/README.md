# 英語脱出 設計書

英語が読めて、聞けて、相方に英語で伝えられないと出られない脱出ゲーム。
- シリーズ設計: Claude Doc「英語脱出シリーズ 設計（ステージ1まで）」 https://claude.ai/artifact/7pzu7wkJhgJ4iofbouvHrk
- **ステージ1のシナリオ・謎・英文の正本**: Claude Doc「英語脱出 ステージ1 シナリオと謎解き設計（改訂版）」 https://claude.ai/artifact/X5DcV8kMCyTJShSitM4Q1Z 。ゲーム内の英文はここから写した。答えに関わる語（時刻・数・曜日・日付）は変えない。
- 経緯: 2026-11-16 たたき台（タオル・ミニバー・ブレーカー・留守電の4謎、ひとり用NPCあり、#229）→ 2026-11-17 経太さん「シナリオをきちんと練った上で作り直す」→ 改訂版シナリオで2人用として作り直し。ひとり用は後回し、難しさは改訂版のまま（2026-11-17 経太さん承認）。

- 置き場所: なつめポータル `/eigo-escape/`（`scripts/build-portal.sh` でコピー、ポータル一覧に掲載）
- 構成: `index.html` 1枚。ビルド無し。外部は Supabase JS（CDN、版固定）と Google Fonts の DotGothic16 だけ。

## 遊び方（ふたり用）

- 「個室を作る」でランダム6桁の `?room=` を作り、番号かURLを相方に送る。同じ番号の人どうしが同じ個室。それぞれ Room 401 / 402 を選ぶ（相方が使っている部屋は選べない）。相方の部屋は最後まで見えない。
- ひとり用は準備中（タイトルに明記）。作るときは402の役を隣室の客が務め、手紙を音声で読み上げる形（改訂版Docの案）。

## 物語

1976年秋、海辺の「The Lantern House Hotel」。401の音楽教師エリーと402の灯台無線係ジェームズが、連絡用ドアの下のメモだけで恋に落ちた。今夜、嵐で停電し、プレイヤー2人は401/402（「手紙の部屋」）に閉じ込められる。キーパッドの番号は「ドアが開いた日。月が先、日が後」。各部屋にはその部屋の住人が**受け取った**手紙だけがある（401=ジェームズの手紙、402=エリーの手紙）。破れた手紙J3・E3は上半分だけだと別れ話に見え、下半分がそろうと本当の結末がわかる。

## しくみ

- **2人の同期**: Supabase Realtime の broadcast と presence（**DBの表は使わない**）。チャンネル名 `eigo-escape:s1v2:<6桁>`（旧版と混ざらないよう `s1v2` を付けた）。
- 共有する `G`: 解いた謎、鍵の状態、連絡用ドア、メモ、ヒント回数、日本語びん回数、開始・クリア時刻。変化のたびに `G` 全体を送り、受け手は `merge`（謎は和集合、鍵は最大値、メモは id で和集合）。入室時は相手に送り返してもらう（`ask`）。
- **鍵の受け渡し**: 鍵ごとに 0=無し / 1=見つけた側 / 2=ドアの下から相方へ / 3=使った。大きくなる方向にしか進まないので最大値で同期できる。滑らせるとメモ欄に「A small key slides under the door. Tag: ...」が両方に出る。連絡用ドアの鍵は滑らせず402で使う。
- 自分だけの `L`（部屋、見ている物、ダイヤル、下書き、ヒント段階、留守電を聞いたか）は送らない。両方とも `localStorage`（`eigo-escape:s1v2:<6桁>`）にも保存し、再読み込みしても続きから。
- **破れた手紙**: 上半分だけのときは下端をギザギザに切って見せ、下半分が出たら「torn here」の線で1通につなげる。
- **音声**: 留守電（ミア）、テープ（ジェームズ、男性の声を優先。無ければ声を低くする）、結末（ミア）。ブラウザの音声合成で、文ごとに順に読む（`speak()` だけで鳴らすので後で良い音声に差し替えられる）。テープの字幕は、402で謎4のヒントを2段目まで開くと出せる。留守電と結末の字幕はいつでも出せる。
- **日本語に逃げない工夫**（旧版から継続）: ドアの下のメモは英字（ASCII）だけ。お助けフレーズ17個（Can you spell it? / What is the date on it? / Who wrote it? / Read the last line, please. / I'm sliding a key under the door. / Did you get it? を追加）。「日本語びん」は自己申告。単語タップで意味（`DICT`）、和訳は「訳」を押したときだけ。

## ヒント

謎ごと・部屋ごとに3段階（1段目=どこを見るか、2段目=相方に何を聞くか、を英語で／3段目だけ日本語で答えまで）。「ヒント」ボタンで、今手が届く未解決の謎から選ぶ。回数はクリア画面に出るだけ。答えに関係のない物を調べ続けても、ゲーム側からは教えない。

## クリア後

ミアの声（祖父母がヘイル夫妻だと明かす）、連絡用ドアを開けていればE.&J.のメモ、物語を日付順に読み返す（J1→E1→J2→E2→J3→E3）、クリア時間・ヒント・日本語びん、単語と言い回し22個（音声つき）、ふたりのメモの記録。「部屋を入れ替えてもう一度」で新しい個室を作り、メモで相方に番号を知らせる（相方の画面に「そこへ移る」が出る）。
