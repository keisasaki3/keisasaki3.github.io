# 英語脱出（仮）設計書

英語が読めて、聞けて、相方に英語で伝えられないと出られない脱出ゲーム。
シリーズ設計は Claude Doc「英語脱出シリーズ 設計（ステージ1まで）」 https://claude.ai/artifact/7pzu7wkJhgJ4iofbouvHrk 。
このフォルダはステージ1のたたき台。2026-11-16 経太さん「作ってみてなつめポータルにおいて」。

- 置き場所: なつめポータル `/eigo-escape/`（`scripts/build-portal.sh` でコピー、ポータル一覧に掲載）
- 構成: `index.html` 1枚。ビルド無し。外部は Supabase JS（CDN、版固定）と Google Fonts の DotGothic16 だけ。
- 名前は仮。

## 遊び方

- **ふたりで**: 「個室を作る」でランダム6桁の `?room=` を作り、番号かURLを相方に送る。同じ番号の人どうしが同じ個室。それぞれ Room 401 / 402 を選ぶ（相方が使っている部屋は選べない）。相方の部屋は最後まで見えない。
- **ひとりで**: プレイヤーは Room 401。Room 402 はNPCのリベラさんが内線電話で務める。質問と頼みごとは英文のボタンで選び、返事は音声（字幕・訳はボタン）。AIは使わない（受け答えは全部台本）。

## 2人の同期

- Supabase Realtime の broadcast と presence（暗記大戦と同じ。**DBの表は使わない**）。チャンネル名 `eigo-escape:<6桁>`。
- 共有するのは `G`（解いた謎、メモ、ヒント回数、日本語びん回数、開始・クリア時刻、留守電2を聞いたか）だけ。変化のたびに `G` 全体を送り、受け手は和集合でまとめる（`merge`）。入室時は相手に送り返してもらう（`ask`）。
- 自分だけの状態 `L`（部屋、開いている物、ブレーカー盤、選んだ色、下書き）は送らない。
- 両方とも端末の `localStorage`（`eigo-escape:<部屋>`）にも保存するので、再読み込みしても続きから。

## 日本語に逃げない工夫

- ドアの下のメモは英字（ASCII）しか入らない。日本語は入力しても消える。
- お助けフレーズ（What do you see? / Can you read it to me? など13個）をタップでメモ欄に入れられる。
- 「日本語びん」：声で遊んでいてつい日本語を使ったら自己申告で押す。罰なし、クリア画面に回数が出る。
- 文書の単語はタップで意味（`DICT`）。和訳は「訳」を押したときだけ。

## ステージ1「The Hotel Rooms」

嵐で停電、4階の電子錠が止まった。401と402の間の連絡用ドアは鍵がかかっていて、下の隙間からメモだけ通る。

| 謎 | 錠がある部屋 | 手がかりがある部屋 | 答え | 英語 |
| --- | --- | --- | --- | --- |
| 1 引き出し | 402 机の引き出し（3色） | 402 清掃係のメモ「401のタオルの色を大きい順に」＋ 401 浴室のタオル（bath towel=blue / hand towel=white / washcloth=yellow） | blue, white, yellow | タオルの種類と大きさ、色 |
| 2 金庫 | 401 金庫（4桁）と付箋「取った物の合計、ドットなしで」 | 401 ミニバー在庫表と中身 ＋ 402 引き出しの料金表 | 水2本5.00＋炭酸3.75＋チョコ3.50＝12.25 → 1225 | a bottle of / a can of / a bag of、値段の言い方 |
| 3 ブレーカー | 402 クローゼットの盤（ダイヤル OFF/1/2/3、メインスイッチ、緑ランプ、赤ボタン） | 401 金庫の手順書 | ダイヤルOFF → スイッチ上げ（緑点灯）→ ダイヤル2 → 赤ボタン | before / until / after / not 3。順番を間違えると盤が最初に戻る（罰なし） |
| 4 出口 | 両方の部屋のドアの数字キー（電源復旧後に動く） | 401 の留守電2（各桁の決め方）＋ 402 ハンガー7本・止まった時計9:15 ＋ 401 枕3つ（クッションは数えない） | 4793 | 聞き取り、How many、a quarter past nine |

シリーズ設計Docの表から1点変えた: 謎1の錠を 401 から 402 に移した。401 にタオルと錠が両方あると、並べ方6通りを総当たりで1人で解けてしまうため。

留守電1（両方の部屋）が状況と最初の一歩（402の机のメモ）を伝える。留守電2は電源復旧後に 401 だけに入る。

## ヒント

謎ごと・部屋ごとに3段階（英語 → やさしい英語 → 日本語で答えまで）。回数はクリア画面に出るだけ。

## クリア後

クリア時間、ヒント回数、日本語びん回数、このステージの単語と言い回し22個（音声つき）、ふたりのメモの記録。
ふたりの場合は「部屋を入れ替えてもう一度」で新しい個室を作り、メモで相方に番号を知らせる（相方の画面に「そこへ移る」が出る）。
